# 🃏 Колода Anki: 160 вопросов + 45 формул

Интервальное повторение — самый надёжный способ не забыть курс через месяц. Колода собрана автоматически из [160 вопросов с собеседований](../README.md#questions) и ключевых формул [шпаргалки](../README.md#cheatsheet).

## Как импортировать

1. Скачайте [`math-for-ai-2026.tsv`](math-for-ai-2026.tsv) (кнопка «Download raw file»).
2. Anki → **Файл → Импорт** → выберите файл. Anki 2.1.55+ сам прочитает настройки из заголовка: разделитель — табуляция, HTML включён, третья колонка — теги.
3. Тип заметки — «Простая» (Basic), колода — новая, например «Математика для ИИ».

## Теги

| Тег | Что внутри |
|-----|-----------|
| `math4ai::линал`, `::анализ`, `::оптимизация`, `::вероятности`, `::статистика`, `::информация_метрики`, `::dl_генеративные` | основные модули |
| `math4ai::база`, `::продвинутое`, `::прикладное` | база, модули 14–17 и 18–23 |
| `math4ai::формулы` | формулы для запоминания |
| `level::junior`, `level::middle`, `level::senior` | уровень вопроса |

Совет: начните с `level::junior`, затем добавляйте по одному тегу в неделю. 15–20 новых карточек в день — комфортный темп.
